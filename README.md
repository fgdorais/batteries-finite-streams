# Batteries Cell Template

Use this template to create a repository for a Batteries Cell. Just click the
"Use this template" button and make sure to turn on the "Use all branches"
option.

Then, in order for the CI/CD workflows to run properly, [create a personal
access token][1] with access to this repository and with read & write
permissions for content, pull requests, and workflows. Save this token into a
repository secret called `BATTERIES_CELL_TOKEN`.

Finally, edit this README, the lakefile and anything you need for your project.
The important part is to keep the GitHub workflows.

[1]: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens#creating-a-fine-grained-personal-access-token
